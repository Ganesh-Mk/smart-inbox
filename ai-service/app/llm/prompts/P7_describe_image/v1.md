Describe this image, which was embedded in a document sent to a drug safety mailbox.

It has already passed a filter for size and colour variance, so it is unlikely to be a logo — but
say so plainly if it turns out to be one.

Describe only what is visible. One short paragraph. Do not diagnose, do not speculate about
cause, and do not assume the image shows a defect merely because it was attached to a complaint.

Choose the category that fits:
- `PRODUCT_DEFECT` — the product or its packaging, showing damage, contamination or an anomaly
- `CLINICAL_PHOTO` — a patient, a body part, a rash, an injection site
- `FORM_CHECKBOX` — part of a form: ticks, signatures, handwritten field entries
- `CHART` — a graph, a table rendered as a picture, a lab trace
- `OTHER` — anything else, including logos and decorative images

Set `mentions_defect` when the image itself shows a physical product problem. Set
`mentions_injury` when it shows harm to a person. Both are `false` for a chart or a logo.

Put any legible text in `contains_text`, verbatim — a batch number or expiry date visible on a
photographed carton is often the most useful thing in the image.

`confidence` is how sure you are of the description, using the rubric in the system prompt. A
blurry photograph honestly described at 0.4 is more useful than a confident invention.
