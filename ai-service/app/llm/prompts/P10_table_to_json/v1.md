Read this table image and return its contents as structured rows.

The table was detected by its geometry but had no ruling lines the parser could follow, so it is
being read visually instead.

Rules:

1. `headers` is the header row. If the table genuinely has no header row, return an empty array
   rather than promoting the first data row.
2. Every entry in `rows` must have exactly as many cells as there are headers. Pad with empty
   strings for blank cells — never drop a cell, or every column after it shifts.
3. Transcribe cells verbatim, including units and symbols: "640", "U/L", "10 – 40", "H".
4. Do not compute, total, reformat or reorder anything.
5. Merged cells: repeat the value in each column it spans.
6. `caption` is any title or caption shown with the table, or an empty string.

`confidence` reflects how cleanly you could read the structure. Lower it when column boundaries
were ambiguous or cells were hard to read.
